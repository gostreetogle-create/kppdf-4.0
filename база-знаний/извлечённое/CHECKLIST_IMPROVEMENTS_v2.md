## ФАЗА 1: АКТУАЛИЗАЦИЯ ДО ANGULAR 21 (СИГНАЛЫ)

### 1.1 Signal Forms вместо Template-driven Forms
**Что:** Заменить `FormsModule` + `ngModel` на новый `form()` Signal Forms API
**Почему:** Signal Forms (Angular 21) — нативный, типо-безопасный, без zone.js
**Где:** Все формы в проекте
**API:** `form()`, `submit()`, `validate()`, `validateStandardSchema()`, `debounce()`, `FormValueControl`
**Статус:** [⊘] Отложено — Signal Forms экспериментальный в v21, ждём стабилизации

### 1.2 httpResource вместо HttpClient для API-вызовов
**Что:** Использовать `httpResource()` — сигнал-ориентированный HTTP клиент
**Почему:** Автоматический refetch при изменении параметров, встроенная типизация
**Где:** `api.service.ts`, все сервисы
**Статус:** [ ] Ожидает

### 1.3 linkedSignal для производного состояния
**Что:** Использовать `linkedSignal()` вместо `computed()` + ручных `effect()`
**Где:** Где нужно двухстороннее связывание сигналов
**Статус:** [ ] Ожидает

### 1.4 model() inputs для two-way binding
**Что:** Использовать `model()` вместо `input()` + `output()` для two-way binding
**Где:** `kp-toggle`, `kp-select`, другие интерактивные компоненты
**Статус:** [ ] Ожидает

### 1.5 Zoneless Change Detection
**Что:** Отключить zone.js, перейти на полностью signal-based change detection
**Почему:** Меньше бандл, быстрее рендеринг, современный подход
**Где:** `app.config.ts` — добавить `provideExperimentalZonelessChangeDetection()`
**Статус:** [⊘] Отложено — zoneless экспериментальный в v21

### 1.6 @defer для ленивой загрузки компонентов
**Что:** Обернуть тяжёлые компоненты в `@defer` блоки
**Где:** Таблицы с данными, диалоги, редактор документов
**Статус:** [ ] Ожидает

### 1.7 @let в шаблонах
**Что:** Использовать `@let` для локальных переменных в шаблонах
**Где:** Все шаблоны с повторяющимися выражениями
**Статус:** [ ] Ожидает

### 1.8 afterRenderEffect вместо ручных DOM-манипуляций
**Что:** Использовать `afterRenderEffect()` для безопасных DOM-операций
**Где:** `kp-table`, компоненты с canvas
**Статус:** [ ] Ожидает
