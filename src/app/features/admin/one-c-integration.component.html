📖 Как настроить интеграцию

Шаг 1

В конфигураторе 1С создайте HTTP-сервис с методами import и export. Сервис должен принимать и возвращать JSON.

Шаг 2

Опубликуйте HTTP-сервис на веб-сервере 1С и получите URL вида: http://ваш-сервер-1с/имя-базы/hs/обмен

Шаг 3

Укажите URL, логин и пароль в настройках выше. Включите интеграцию.

Шаг 4

Запустите ручную синхронизацию для проверки. При успехе настройте интервал автообмена.

ℹ️ Формат обмена

Эндпоинт для приёма данных от 1С: POST /api/v1/one-c/import

Данные передаются в JSON формате. Полная спецификация API доступна в документации.
