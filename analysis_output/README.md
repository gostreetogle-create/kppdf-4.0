# Анализ предметной области для CRM/PLM-системы

## 📂 Структура отчёта

| Файл | Описание |
|------|----------|
| `01_summary.md` | Резюме анализа: релевантные файлы, предметная область, выводы |
| `02_data_model.json` | Полная модель данных (12 таблиц, связи, индексы) |
| `03_business_processes.md` | 6 бизнес-процессов + статусные модели + бизнес-правила |
| `04_advice.md` | Архитектура, технологии, риски, интеграции, roadmap |
| `05_er_diagram.mermaid` | ER-диаграмма на языке Mermaid |

## 🧬 Модель данных включает

- **organizations** — контрагенты (юридические лица, бюджетные учреждения)
- **clients** — клиенты-физические лица (контакты, ИП)
- **product_categories** — иерархические категории товаров
- **products** — номенклатура спортивного оборудования
- **product_specifications** — гибкие характеристики (EAV-модель)
- **product_documents** — паспорта, чертежи, сертификаты
- **commercial_proposals** — коммерческие предложения
- **commercial_proposal_items** — позиции КП
- **contracts** — договоры (поставки, подряда, лизинга)
- **invoices** — счета на оплату
- **tenders** — тендеры/аукционы (44-ФЗ, 223-ФЗ)
- **projects** — проекты строительства/монтажа
- **users** — пользователи системы
